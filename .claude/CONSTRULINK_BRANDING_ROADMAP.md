## 📌 CONTEXTO ESTRATÉGICO

### La Empresa
- **Nombre**: ConstruLink
- **Sector**: PropTech / ConstructionTech (Argentina)
- **Modelo**: B2B SaaS - Marketplace + Compliance + ERP + Escrow
- **Mercado**: Constructoras medianas ($20M-$100M anuales), desarrolladoras, estudios de arquitectura
- **Diferencial**: Única plataforma que integra 4 pilares (marketplace inteligente + validación legal + gestión digital + pagos asegurados)

### Identidad de Marca
- **Propuesta Emocional**: "Donde se construye confianza"
- **Tone of Voice**: Profesional formal corporativo (Procore, Notion style)
- **Posicionamiento**: Experto confiable, no vendedor
- **Personalidad**: Claro, directo, serio, sin pretensiones

## 🎯 SKILLS ESPECIALIZADOS A CREAR

### SKILL 1️⃣: ESTRATEGA DE BRANDING & RESEARCH
**Objetivo**: Definir identidad estratégica + briefing creativo

#### Prompt Especializado:
```
Eres un estratega de branding especializado en SaaS y startups B2B.
Contexto de ConstruLink:
- Plataforma que digitaliza la cadena de construcción argentina
- Integra marketplace + compliance + ERP + escrow
- Público: constructoras medianas, desarrolladoras, estudios de arquitectura
- Diferencial: única con 4 pilares integrados
- Tone: profesional formal corporativo
- Problema a resolver: informalidad, desconfianza, herramientas del siglo XX

Tu tarea:
1. Analizar el posicionamiento estratégico
2. Identificar arquetipos de marca relevantes
3. Definir valores, misión, visión
4. Crear buyer personas detalladas
5. Desarrollar narrativa de marca
6. Generar brief creativo para diseñador gráfico

Entrega: Documento de 2000-2500 palabras con análisis, arquetipos, personas, narrativa y brief creativo.
```

**Deliverables esperados**:
- [ ] Análisis de posicionamiento (vs Procore, Workana, ConstruEx)
- [ ] 3 arquetipos de marca candidatos
- [ ] 4-5 buyer personas detalladas
- [ ] Narrativa de marca coherente
- [ ] Brief creativo para diseñador (inspiraciones visuales, referencias)

### SKILL 2️⃣: DISEÑADOR GRÁFICO - IDENTIDAD VISUAL
**Objetivo**: Logo, tipografía, paleta de colores, guía visual

#### Prompt Especializado:
```
Eres un diseñador gráfico profesional especializado en identidad corporativa para SaaS y B2B.

Contexto:
- Marca: ConstruLink (plataforma construcción)
- Tone: profesional formal corporativo
- Inspiraciones: Procore, Notion, Figma, Stripe (UI limpia, confianza, profesionalismo)
- Propuesta emocional: "Donde se construye confianza"

Tu tarea (fase 1: conceptos):
1. Generar 3-5 conceptos de logo con descripción detallada
2. Justificar cada concepto (simbología, psicología del color)
3. Definir tipografía corporativa (2 familias: display + texto)
4. Crear paleta de colores con psicología:
   - Primario (confianza, profesionalismo)
   - Secundario (energía, innovación)
   - Neutros (claridad, accesibilidad)
5. Generar mockups conceptuales (logo en diferentes tamaños)
6. Documentar guía de estilos preliminar

Entrega: Documento con conceptos, justificaciones, tipografía, paletas y primeras aplicaciones visuales.
```

**Deliverables esperados**:
- [ ] 3-5 conceptos de logo con wireframes/descripciones
- [ ] Justificación de cada concepto
- [ ] 2 familias tipográficas seleccionadas
- [ ] Paleta de colores (primario, secundario, neutros)
- [ ] Mockups en diferentes contextos
- [ ] Guía visual preliminar

## 🎨 REFERENCIAS VISUALES INSPIRACIONALES

### Nivel de Profesionalismo Requerido:
- **Procore** (SaaS construction) - corporativo, confianza
- **Notion** (workspace) - minimalista, moderno
- **Stripe** (fintech) - limpio, premium
- **Figma** (design tool) - innovador pero accesible
- **Slack** (communication) - amigable + profesional

### Paleta Inspiracional (referencia):
- **Azul profesional** (confianza, seguridad) - #0066CC o similar
- **Verde/Naranja energía** (innovación, construcción) - acento
- **Grises neutros** (claridad, accesibilidad)

### Tipografía Inspiracional:
- Display: Sans-serif moderno (Inter, Poppins, DM Sans)
- Body: Sans-serif legible (Roboto, Open Sans, System Font)
